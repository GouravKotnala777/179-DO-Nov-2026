# some codes and commands

  - System and OS Information

    uname -a       =>  to display complete system and kernel information
    uname -r       =>  to display the Linux kernel version
    hostname       =>  to display the system hostname
    hostnamectl    =>  to display hostname, operating system and system details
    cat /etc/os-release =>  to display Linux distribution and version
    uptime         =>  to show how long the system has been running

  - CPU Information

    lscpu          =>  to display CPU architecture, cores and other CPU details
    nproc          =>  to show the number of available processing units
    cat /proc/cpuinfo =>  to display detailed CPU information

  - RAM and Memory Information

    free -h        =>  to display RAM and swap memory usage in human-readable format
    cat /proc/meminfo =>  to display detailed memory information
    vmstat         =>  to display memory, CPU and process statistics

  - Disk and Storage Information

    df -h          =>  to display disk space usage in human-readable format
    du -sh         =>  to display the total size of the current directory
    du -sh *       =>  to display the size of each item in the current directory
    lsblk          =>  to list storage devices and partitions
    sudo fdisk -l  =>  to display disk partition information

  - Network Information

    ip addr        =>  to display network interfaces and IP addresses
    ip route       =>  to display the network routing table
    hostname -I    =>  to display the system's IP addresses
    ss -tuln       =>  to display listening TCP and UDP ports
    ping google.com =>  to test network connectivity

  - Process and Resource Monitoring

    top            =>  to monitor running processes and system resource usage
    ps aux         =>  to list running processes
    pgrep -a node  =>  to find processes by name and display their commands
    whoami         =>  to display the current username
    who            =>  to show currently logged-in users

  - Additional Commands

    lspci          =>  to list PCI devices
    lsusb          =>  to list connected USB devices
    netstat -tuln  =>  to display listening TCP and UDP ports (requires net-tools)
    curl -I URL    =>  to display HTTP response headers from a URL
    wget URL       =>  to download a file from a URL
    ssh user@host  =>  to connect securely to a remote server
